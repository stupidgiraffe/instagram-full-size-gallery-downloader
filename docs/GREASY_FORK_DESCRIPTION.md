**Instagram Full-Size Gallery & Downloader** turns Instagram profiles and supported feeds into a continuous, uncropped photo and video gallery built for actually browsing the media—not just the grid.

Instagram's native profile layout crops portrait images into thumbnails and makes large collections awkward to explore. This userscript restacks the available media into a dedicated gallery with full-aspect images, continuous navigation, smooth zooming, optional load-all, and direct downloads.

## Highlights

- Complete, uncropped portrait and landscape images
- Full-size image and video gallery
- Fit grid, masonry, classic wall, and contact-sheet layouts
- Full-frame or cropped contact-sheet thumbnails
- Compact, comfortable, and large viewer opening sizes
- Click-to-zoom with matching plus/minus cursor behavior
- Mouse-wheel and two-finger trackpad zoom from 25% to 600%
- Drag-to-pan while zoomed
- Continuous previous/next browsing
- Automatic loading near the end of the gallery
- Manual **Load more** and optional **Load all**
- Direct image downloads
- Direct video downloads
- Open media or the original Instagram post
- Copy post URL or direct media URL
- Export loaded media URLs
- Image/video filtering and optional captions
- Persistent settings
- Dark and light themes
- No analytics, ads, tracking, or telemetry

## Viewer controls

- **Click image:** zoom in; click the minus cursor to return to fit
- **Mouse wheel / two-finger scroll:** fine zoom
- **Drag:** pan while enlarged
- **Arrow keys:** previous / next
- **F:** reset view
- **D:** download current media
- **Esc:** close viewer
- **Hide controls / Show controls:** collapse or restore the bottom information/action bar when you want the maximum unobstructed viewing area

## Supported Instagram pages

The script is designed for:

- Profiles
- Tagged feeds
- Home feed where Instagram's current logged-in web endpoint permits it
- Individual post and reel pages through visible-media harvesting

Instagram changes its private web responses frequently. If something stops loading after an Instagram update, please report it through GitHub Issues with your browser, userscript manager, script version, and page type.

## Privacy and permissions

The userscript runs locally in your browser. It contains no analytics, advertising, account tracking, remote configuration, or external telemetry.

Network access is limited to Instagram API/media hosts required to load and download media already available to your logged-in browser session. Userscript-manager permissions are used for saved settings, clipboard actions, downloads, and Instagram network requests.
