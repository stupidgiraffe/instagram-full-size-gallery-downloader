# Security policy

## Supported version

Only the latest published version is supported.

## Reporting a vulnerability

Please do not publish account, cookie, token, or private-media details in a public issue.

For ordinary bugs that contain no sensitive information, use the GitHub bug-report template. For a vulnerability involving credential exposure or unintended data access, contact the maintainer privately through the contact method listed on the maintainer’s GitHub profile.

The script should never request passwords, export cookies, transmit analytics, or send browsing data to non-Instagram services.
